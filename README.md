# IronLog — Strength Tracker

A mobile-first gym tracking app built with React + Vite.

## Features
- Workout view with rest timer and set logging
- Smart planner with recovery tracking
- Progress charts and heatmap
- Workout builder with templates
- Weekly schedule
- Data stored in localStorage

## Setup

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push to GitHub
2. Import repo at vercel.com
3. Vercel auto-detects Vite — hit Deploy

## Add to iPhone Home Screen

1. Open your Vercel URL in Safari
2. Tap Share → Add to Home Screen
3. Tap Add

## Icons

Replace `public/icon-192.png` and `public/icon-512.png` with your own 
icons (convert `logo.svg` at svgtopng.com or similar).
